# Examples

These examples target the synthetic fixture knowledge base generated by this
repository. They are for API and workflow shape only; they are not examples of
official DICOM Standard content.

Build a fixture database before running examples that require `--db`:

```bash
dicom-kb build-fixture --edition 2026b --db /tmp/dicom-kb-fixture.sqlite --force
```

To use a locally fetched official edition instead, point `--db` at the
externally cached build under `~/.cache/dicom-standard-kb/db/<edition>.sqlite`
and pass the matching concrete `--edition`.
